# 防災知識文件

這個資料夾是聊天助理「防災知識」路由的語料：災害應變須知與警戒等級說明。
避難所在哪裡、容量多少不在這裡，那是 `data_for_refuge/` 的工作。

## 檔案

| 檔案 | 內容 |
|---|---|
| `typhoon.md` | 颱風警報、颱風強度分級、颱風前／颱風時／颱風後 |
| `earthquake.md` | 地震震度分級、地震前／地震時／地震後 |
| `debris_flow.md` | 土石流是什麼、黃色／紅色警戒、警戒基準值、前兆、疏散 |
| `tsunami.md` | 海嘯資訊種類、預估波高分級、前兆、來襲時與過後 |
| `flood.md` | 大雨／豪雨分級、淹水警戒、淹水前與淹水時 |

## 格式

每一段是一個檢索單位，以 `## <id>｜<標題>` 開頭，接著是欄位清單，空一行之後是正文：

```
## typhoon-warning｜颱風警報：海上與陸上
- hazard: typhoon
- kind: alert
- source: 中央氣象署《颱風百問》第 88 題
- url: https://www.cwa.gov.tw/V8/C/K/Encyclopedia/typhoon/typhoon.pdf
- retrieved: 2026-10-27

正文……
```

- `hazard`：typhoon / earthquake / debris_flow / tsunami / flood
- `kind`：`alert`（警戒、分級的意義）、`before`（災前準備）、`during`（災時應變）、`after`（災後）、`about`（災害本身的說明）
- `source`、`url`：這一段改寫自哪一份官方文件；一段有兩個來源就寫兩行
- `retrieved`：擷取日期。官方標準會修訂（例如海嘯分級 114 年 2 月改版），日期用來判斷是否需要重新核對

## 撰寫規則

- 正文是依官方文件改寫的摘要，不加入來源裡沒有的事實。數字（雨量門檻、波高、時數、震度）照抄原文。
- 一段只講一件事，長度大約 100～300 字，讓檢索能精準命中。
- 用語跟著官方文件走（例如「預防性疏散撤離」「垂直避難」），使用者問的是口語，檢索靠向量相似度補上。
- 只有官方二手轉述、找不到原文的內容，在 `source` 註明「新聞引述」，並列在下方「待確認」。

## 授權

- 中央氣象署、內政部消防署（含消防防災館 tfdp.com.tw）、農業部農村發展及水土保持署的網站資料，依各自的「政府網站資料開放宣告」，以《政府資料開放授權條款－第1版》提供，可改作、重製，使用時須註明出處。
- 中央氣象署《海嘯資訊發布作業要點》《有感地震報告發布作業要點》在政府資料開放平台（data.gov.tw/dataset/174286、174285）以同一授權條款釋出。
- 每一段的 `source` / `url` 就是出處標示。回答引用知識文件時，也會把出處一起交給使用者。

## 英文翻譯（`en/`）

英文模式用的翻譯，檔名與段落 id 跟中文一一對應。格式比中文簡單，出處沿用中文段落的：

```
## typhoon-warning｜Typhoon warnings: sea warnings and land warnings
- reviewed: no

（英文正文）
```

- `reviewed: no` 的段落不會上線：英文模式照樣顯示中文原文，前面加一句「英文版尚未審核」。翻錯的防災資訊就是錯誤的防災資訊，跟模型改寫原文是同一種風險。
- 審過一段，就把那一段改成 `reviewed: yes`，重啟服務（或下次 `/api/sync`）後英文版才會出現。
- 翻譯原則同中文：不增減內容，數字照抄；台灣特有的名稱（機關、警戒名稱、電話號碼）附中文原文。
- 中文段落改了內容，對應的英文要一起改，並改回 `reviewed: no` 重新審。
- 載入時會檢查：英文檔裡的 id 必須存在於中文檔；中文有、英文沒有的段落照樣顯示中文。
